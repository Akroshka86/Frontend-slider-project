# Глобальный чат

**Глобальный чат** — это веб-приложение для обмена сообщениями в реальном времени между авторизованными пользователями. Проект реализован с использованием **React** и **Redux Toolkit**.  

Пользователи могут регистрироваться, входить в систему, отправлять и просматривать сообщения в общем чате. Состояние приложения сохраняется между перезагрузками страницы.

---

## Функционал

1. **Регистрация и авторизация**  
   - Пользователь может зарегистрироваться с уникальным логином и паролем.
   - После регистрации интерфейс автоматически переключается на страницу входа.
   - Авторизация позволяет получить доступ к глобальному чату.

2. **Глобальный чат**  
   - Отображение сообщений всех авторизованных пользователей.
   - Возможность отправки новых сообщений.
   - Сообщения сохраняются на сервере и автоматически подгружаются при обновлении страницы.

3. **Сохранение состояния**  
   - Текущий пользователь сохраняется в **LocalStorage**, что позволяет оставаться авторизованным после перезагрузки страницы.

4. **Уведомления**  
   - Уведомления об успешной регистрации или авторизации.
   - Ошибки при регистрации или авторизации (например, пользователь уже существует или неверный пароль).

5. **Virtual Scroll** (дополнительно)  
   - Используется для эффективного отображения большого количества сообщений, что повышает производительность.

6. **Выход из аккаунта**  
   - Пользователь может выйти из системы с очисткой данных из LocalStorage.

---

## Технологии

- **React** — библиотека для построения интерфейсов.
- **Redux Toolkit** — управление состоянием приложения.
- **TypeScript** — статическая типизация.
- **React Window** — виртуальный скролл для оптимизации списка сообщений.
- **CSS / Flexbox** — стилизация компонентов.
